<EXTREMELY_IMPORTANT>
OpenSpec 工作流已启用。

你可以使用以下 slash commands：

**核心流程**
- /opsx-propose <变更名> — 创建完整的 proposal/specs/design/tasks
- /opsx-explore <主题> — 需求澄清与方案探索
- /opsx-apply <变更名> — 执行 tasks 实现变更
- /opsx-archive <变更名> — 归档已完成变更

**规划增强**
- /opsx-new-change <变更名> — 启动新变更，逐步创建 artifact
- /opsx-continue-change <变更名> — 继续创建下一个 artifact
- /opsx-ff-change <变更名> — 快速生成全部 planning artifacts
- /opsx-update-change <变更名> — 更新 planning artifacts 并保持一致性

**流程管理**
- /opsx-sync-specs <变更名> — 同步 delta specs 到 main specs
- /opsx-verify-change <变更名> — 验证实现与 artifact 匹配
- /opsx-bulk-archive — 批量归档多个变更
- /opsx-onboard — 引导式完整工作流教学

推荐流程：propose → specs → design → tasks → apply → archive
</EXTREMELY_IMPORTANT>
